아래 버튼은 공개된 서버 코드만 복사합니다. API 키나 접속 암호를 입력할 필요가 없습니다.

버튼을 누른 뒤 Cloudflare 코드 편집 탭으로 돌아가세요.

  1. Cloudflare 편집기의 worker.js 코드 영역을 누르세요.
  2. 전체 선택 → 붙여넣기로 기본 Hello World 코드를 교체하세요. 노트북에서는 코드 영역 클릭 후 Ctrl+A, Ctrl+V를 사용하세요.
  3. 오른쪽 위 Deploy를 누르고 완료될 때까지 기다리세요.
  4. 서버 설정 확인 열기에서 ready: true를 확인하세요. 이 확인은 GPT 생성 요금을 발생시키지 않습니다.

ready가 false이면 OPENAI_API_KEY·OFFICE_ACCESS_TOKEN Secret과 DB 바인딩을 확인하세요. 이 단계는 서버 준비 확인이며 실제 GPT 작업 성공 확인은 아닙니다.
