동백사무실 바로가기 다운로드

Windows 노트북 바탕화면에서 최신 동백사무실을 여는 바로가기 파일입니다.

바탕화면 바로가기 ZIP 다운로드
  1. 파일 탐색기에서 다운로드 폴더를 엽니다. 단축키는 윈도우 키 + E입니다.
  2. 받은 ZIP 파일을 마우스 오른쪽으로 눌러 모두 압축 풀기를 선택합니다.
  3. 안에 있는 동백사무실 파일을 바탕화면으로 옮깁니다.
  4. 더블클릭하면 브라우저에서 사무실이 열립니다.
파일이 저장되지 않으면 이 페이지를 Chrome 또는 Edge에서 열고 다시 다운로드하세요.
